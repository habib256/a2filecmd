                     APPLE TOTAL COMMANDER 1.0  -  ProDOS file manager          
                                                                                
  NAVIGATION                                                                    
 U/D Move up / down                      </> Page up / down (or - +)            
 [/] First / last entry                  TAB Switch panel                       
 RET Open (Right arrow too)              ESC Parent directory (Left too)        
  /  List of volumes                      ,Same directory in other panel        
  '  Jump to next name starting with the key pressed next                       
                                                                                
  FILES                                                                         
 SPC Tag / untag (* after name)           *  Invert tags                        
  C  Copy to the other panel              V  Move (copy, then delete)           
  R  Rename                               D  Delete, directories too            
  K  Make a directory                     S  Sort by name, size or type         
  M  Mark files differing from other pane A  Change type and auxtype            
  L  Lock / unlock (L after name)         X  Run a SYS or BIN program           
  E  Edit a text (on a dir: new file)     I  View as image: HGR/DHGR, raw/RLE   
  P  Pause / resume the Mockingboard music (RET on a .MB file plays it)         
  VIEWERS AND EDITOR                                                            
 RET By type: directory, image (HGR/DHGR, raw or RLE), TXT, SYS runs, else hex  
  T  Text   H  Hex  L/R Prev / next image    ESC Editor menu: save, quit        
 Editor: arrows, DEL, Ctrl-D delete, Ctrl-A/E line ends, Ctrl-P/N pages, Ctrl-T/
BC, V, D act on tagged files; existing files ask Overwrite/Skip/All/None.       
ANYReturn to the panels
