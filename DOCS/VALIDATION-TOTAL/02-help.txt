  NAVIGATION                                                                    
 U/D Move up / down                      </> Page up / down (or - +)            
 [/] First / last entry                  TAB Switch panel                       
 RET Open (Right arrow too)              ESC Parent directory (Left too)        
  /  List of volumes                      =  Same directory in other panel      
  '  Jump to the next name starting with the key pressed next                   
                                                                                
  FILES                                                                         
 SPC Tag / untag: C V D use tags          *  Invert tags                        
  C  Copy to the other panel              V  Move (copy, then delete)           
  R  Rename                               D  Delete, directories too            
  K  Make a directory                     S  Sort by name, size or type         
  M  Mark files differing from other      A  Change type and auxtype            
  L  Lock / unlock (L after name)         X  Run a SYS or BIN program           
  E  Edit a text (on a dir: new file)     I  View as image: HGR/DHGR, raw/RLE   
  P  Pause / resume the music             F  Format a disk (asks twice)         
                                                                                
  VIEWERS AND EDITOR                                                            
 RET By type: dir, image, text, .MB music T  Text    H  Hex                     
 L/R Previous / next image               ESC Editor menu; Ctrl-A/E/P/N/T/B/D    
ANYReturn to the panels
