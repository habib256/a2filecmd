This DEMO folder holds one example of everything A2 File Cmd can open.
Press RETURN on a file to open it by type, or force a viewer: T text,
H bytes, I picture. ESC comes back.

  HGR.RAW      a raw HGR page, 8192 bytes: the six colours in bands
  HGR.RLE      the same card, RLE compressed (HGRR stream)
  DHGR.RAW     a raw DHGR page, 16384 bytes: the sixteen colours
  DHGR.RLE     the same card, RLE compressed (DHRR stream)
               In a picture, LEFT and RIGHT step through the folder.
  WELCOME.MB   a three-voice Mockingboard tune: RETURN plays it, P pauses
  SAMPLE       a text: T reads it page by page, E edits it
  HELLO        an Applesoft program: RETURN or X runs it, T lists it
  README       this text
  TINY.PO      a ProDOS disk image: RETURN opens it as a folder,
               C copies a file out of it
  TINY.2MG     the same image with a 2IMG header
  DOS33.DSK    a DOS 3.3 disk: RETURN shows its catalog, C extracts
  SAMPLE.SHK   a ShrinkIt archive: press ! and pick the extractor,
               the files go to the other panel
  SAMPLE.BNY   the same two files in a Binary II archive: ! again

Nothing here is copied from anywhere: the cards, the tune, the archives
and the images are all generated by tools/mkdemo.py.
