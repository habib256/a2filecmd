CIDERPRESS - sample files from CiderPress II

These files come from the test data of CiderPress II, by Andy McFadden
(https://github.com/fadden/CiderPress2, TestData/fileconv), where they
serve the same purpose: one real file for each format a viewer reads.
They are kept here as they were found, folder by folder:

  GRAPHICS/ESCHERWATER.MAC  a MacPaint picture: MACPAINT
  GRAPHICS/SHAPETABLE/...   three Applesoft shape tables: SHAPES
  GRAPHICS/STANDARD         a hi-res 7 x 8 font: FONTVIEW
  DOCS/PRESIDENTS           an AppleWorks data base: AWDATA
  DOCS/MATH.QUIZ            an AppleWorks spreadsheet: AWDATA
  ARCHIVES/HELLO.AS         AppleSingle, from Mac OS's applesingle tool
  ARCHIVES/GSHK.HFS.AS      AppleSingle v1 by GS/ShrinkIt: a Teach file
  ARCHIVES/MACIP.RES.AS     AppleSingle, a resource-only file of
                            Marinetti (LGPL v2): UNWRAP
  ARCHIVES/SHRINKIT.BSC     ShrinkIt itself, posted in BinSCII: SCIIBIN
  ARCHIVES/ZLINK.01.BSQ     Z-Link, a ShrinkIt archive posted in five
  ... ZLINK.05.BSQ          BinSCII parts: SCIIBIN on the first one
  (both posted to comp.binaries.apple2 by their authors)

Select a file and press Return.
